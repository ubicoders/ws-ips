# 03 Calibrate

Module 2, second half. Intrinsics with Kalibr, then extrinsics with `ips_calib`.

1. Kalibr on your own AprilGrid images; the camchain goes to `calibration/intrinsics/sbNN-camchain.yaml`.
2. Measure the calib board tags with the caliper and put the size in `calibration/ips_calib.yaml`.
3. Set the detectors to `family: april`, `marker_size: 0.185` (or your measured value) in `modules/ips_detect/parameters/detector_params.yaml`. The detectors read it at startup, and the calibration flow of step 4 starts them afresh.
4. Fill `fit_extrinsics` and `reprojection_residual` in `modules/ips_calib/src/fit.rs`, then start the calibration flow, `calib.flow.yaml`: `sb down && sb up calib`, or plain `sb up calib` when no session is running. It builds and starts the cameras, the detectors and `ips_calib` together, and the calibrator's window, `ips_calib`, appears: one tile per camera with the live image, the board tags its detector reports, each labelled `[id]`, and a status line, and a panel underneath with the state, the next step and the keys valid now. When every tile shows the board, press S and keep the board still while each tile counts its frames (`142/300`). When the counters reach the goal, press C to calibrate and read each camera's residual on its tile: green at or under `rms_warn_m` (0.01 m), amber above. Press W, check the files listed with their old and new residual, and press Y to write `calibration/extrinsics/sbNN_full.yaml`; nothing is written before Y. R starts over, and Q or Esc quits. The window needs a display: the calibrator runs inside tmux and inherits `DISPLAY` from the terminal that ran `sb up`.

   Calibration is not part of `sb up`: `ips_calib` is not a node of the default flow, so `sb run ips_calib` is refused while the live pipeline is the active flow (`module ips_calib is not a node of flow default`), and `sb up` refuses a session that already exists, hence the `sb down`. Once `calib` is the active flow, `sb run ips_calib` runs the calibrator again, and `sb run --fg ips_calib` runs it in the current terminal. With `ui: false` in `modules/ips_calib/parameters/calib_params.yaml`, the calibrator runs headless instead: it accumulates until `frames` or `timeout_s`, fits, writes and exits.

Acceptance: `cargo test` inside `modules/ips_calib/` passes, a residual under 1 cm per camera, `sbNN_full.yaml` written for every camera, and the window shows every tile green before W. Then set the detectors back to `aruco`, `0.087` and return to the live pipeline with `sb down && sb up`; `ips_track` loads the new extrinsics at startup.
