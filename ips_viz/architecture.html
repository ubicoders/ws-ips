Where ips_viz sits.

Each box is its own Rust crate, its own process, its own tmux window. The highlighted box is this folder. A box only talks to the next box through a message, never through code.

Where things live

  • yamlworkspace/flow.yaml lists the four always-on modules and the four camera ids.
  • yamlEvery module has its own parameters/*.yaml. It is the only place settings come from.
  • protomessages/custom/*.proto defines the two messages. Each crate compiles them at build time.
  • genswarmbotix_io/ inside each module is generated by sb. Never edit it.

One run, in order

  • 1sb up starts cameras, detectors, tracker, viewer.
  • 2Once per camera placement: detectors on AprilTag, run ips_calib, restart tracker.
  • 3Detectors back on ArUco. Open rerun to watch.
ips_viz · 2 source files · ~1000 lines

Draw the room so a human can check it.x1

No window of its own. It turns messages into drawing commands and streams them to a rerun viewer running next door.

Files

src/main.rsBuilds the wire keys, fetches extrinsics with retries, opens the subscribers, runs the single poll loop.
src/visualize.rsParams, the cube box model, camera extrinsics from JSON, and every rerun call: blueprint, cameras, cubes, plots, images.
src/lib.rs build.rsGlue plus protobuf generation.
swarmbotix_io/subscribers/generatedcube_poses (zenoh) and debug_image (iceoryx2, zero copy).
tests/params.rstestA sample cam_param reply parses. An error reply is rejected.

Reads

  • zenoh.../ips_track/zenoh/cube_poses

  • iox2.../ips_detect-sbNN/iox2/debug_image, optional
  • yamlparameters/viz_params.yaml: cube size, draw scale, cameras, rerun_hz, debug toggles

Writes

  • gRPCrerun+http://127.0.0.1:9876/proxy, a log stream
  • stdouta 10 Hz echo. No files.

The rerun crate version must match the rerun app you installed. Start rerun first.

The viewer is set to Z-down so the ceiling cameras lie flat on the grid.

words that keep showing up

Seven words, plain.

iceoryx2
A mailbox in shared memory. Two programs on the same computer pass a big picture by pointing at it instead of copying it.
zenoh
A post office for small messages. Programs publish to a named key; anyone subscribed to that key gets a copy, even over the network.
protobuf
The packing format for a message. The .proto file is the packing list; each crate generates Rust structs from it at build time.
intrinsics
The lens numbers of one camera: focal length, image centre, distortion. From Kalibr, in camchain.yaml.
extrinsics
Where a camera sits in the room and which way it points: a rotation R and a shift t. Made by ips_calib.
Kabsch fit
Given two lists of matching 3D points, find the one rotation and shift that lay one list on top of the other with the least error. Used twice: for cameras, then for cubes.
rerun
A 3D log viewer. Programs send it points, boxes, images and numbers over time; it draws them with a timeline.
